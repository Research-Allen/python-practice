# A Synaptic Divergence-Guided Growing Feedforward Neural Network via Topological Adaptation

This repository contains the reference implementation of SD-GFNN (Synaptic Divergence-Guided Growing Feedforward Neural Network), benchmark experiments, and consolidated results used in the Neural Processing Letters submission.

## Files
- SD_GFNN_Final.py : Core SD-GFNN implementation
- results.csv : Consolidated benchmark results
- experimental-results-populated.md : Supplementary results tables

## Requirements
Install packages from requirements.txt and run benchmark scripts.
